I'm a **backend software engineer** who cares about the whole life of a service — from API design and data modelling to the containers, reverse proxies and pipelines that keep it running in production.

- 🚢 **Ship it properly:** Docker, Nginx, GitHub Actions CI/CD, Linux servers I operate myself
- 🔎 **Now:** R&D Project Evaluator at **Zaim Teknopark** — reviewing the architecture and delivery plans of backend, cloud and IoT projects
